# Raat Ka Safar

A romantic ghazal with Hindi rap verses, made for night drives. About 2.5 minutes, around 80 bpm.
The lyrics (`lyrics.txt`) are original and were written for this song.

Both takes were generated with ACE-Step 1.5 (turbo DiT) on a CPU, with the same lyrics and style
prompt:

- `p1.mp3`: the 0.6B 5Hz LM planned the song first (`thinking=true`).
- `p2.mp3`: no LM planning.

Style prompt: romantic hindi ghazal fused with mellow hip hop, harmonium, tabla, soft piano, warm
sub bass, lo-fi drums, emotional male ghazal vocal with male rap verses, late night long drive,
slow 80 bpm.
