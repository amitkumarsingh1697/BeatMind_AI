# Raat Ka Safar, v2

Second version, made after feedback on p1 and p2 that the rap did not feel like rap and a few words
were mispronounced (हाथों, रहने, बेबसी).

Changes from v1:

- Rewritten rap verses with denser lines and more internal rhyme.
- Style prompt asks for punchy boom bap drums at 85 bpm and a confident male rapper with a fast,
  rhythmic flow on the rap verses.
- Problem words respelled: रेहने, हातों, बे-बसी.

Both takes used ACE-Step 1.5 (turbo DiT) on a CPU with the 0.6B 5Hz LM planning first
(`thinking=true`):

- `v2-devanagari.mp3`: lyrics in Devanagari with the respellings (`lyrics-devanagari.txt`).
- `v2-roman.mp3`: the same lyrics in Roman letters (`lyrics-roman.txt`).

Style prompt: romantic hindi ghazal fused with hip hop, harmonium, tabla, soft piano, deep sub bass,
punchy boom bap drums, soulful male ghazal singer on verses and chorus, confident male rapper with
fast rhythmic rap flow on rap verses, late night long drive, 85 bpm.
