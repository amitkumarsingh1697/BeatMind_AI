# Glossary

| Term | Meaning |
| --- | --- |
| ADR | Architecture decision record: one decision, its context, options and consequences. |
| C2PA | Coalition for Content Provenance and Authenticity. An open standard for signed "content credentials" embedded in media files. |
| Content ID | YouTube's system that matches uploads against reference files and can claim revenue or block videos. |
| DDEX | Digital Data Exchange, the music industry's metadata standards body. |
| DPDP | India's Digital Personal Data Protection Act 2023 and the DPDP Rules 2025. |
| Draft render | A fast, lower-cost preview of a song. |
| Full render | The final, full-quality version of a take the user keeps. |
| Hinglish | Hindi and English mixed in one sentence, common in Indian lyrics and prompts. |
| Open weights | Model parameters published for download. Open weights do not by themselves allow commercial use; the licence decides. |
| Provenance ledger | BeatMind's append-only record of every input, generation, edit and export for a song. |
| Purchasing-power parity (PPP) pricing | Charging different local prices so a subscription costs a similar share of local spending power. |
| RTM | Requirements traceability matrix: links each requirement to its tests. |
| SGI | "Synthetically generated information", the term used in India's amended IT Rules (2026) for AI-made or altered content, including audio. |
| Stem | One separated part of a song, such as vocals, drums or bass. |
| Take | One generated version of a song or section. |
| Watermark | An inaudible signal embedded in audio that identifies it as AI-generated or links it to a record. |
| WCAG 2.2 AA | Web Content Accessibility Guidelines version 2.2, level AA, the accessibility standard set for BeatMind. |
