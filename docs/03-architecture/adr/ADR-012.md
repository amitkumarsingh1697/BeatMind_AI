# ADR-012: Delivery: GitHub Actions, Docker, OpenTofu, trunk-based development

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

Public repository; three developers; need repeatable builds and safe releases.

## Options considered

1. Manual deploys.
2. GitHub Actions CI/CD with container images and infrastructure as code.

## Decision

Option 2: trunk-based development with short-lived branches and pull requests; CI runs unit, integration, lint, dependency and secret scans; images built once and promoted from staging to production; OpenTofu for infrastructure; Renovate for dependency updates.

## Consequences

Reproducible, auditable releases. Secrets must never be committed because the repository is public.
