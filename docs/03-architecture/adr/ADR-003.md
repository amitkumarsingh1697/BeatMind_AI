# ADR-003: Web: Next.js with React and TypeScript

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

Public song pages need server-side rendering for search and link previews; the app needs i18n (English, Hindi first) and must work on low-end Android phones (REQ-NFR-10).

## Options considered

1. Next.js.
2. Single-page React app with no server rendering.
3. Server-rendered Java templates.

## Decision

Option 1, with next-intl for translations, Tailwind CSS, and a PWA manifest.

## Consequences

Server rendering for public pages, a large hiring pool and component ecosystem, and simple hosting on a Node container. Bundle size must be watched for low-end phones (performance budget in the UX spec).
