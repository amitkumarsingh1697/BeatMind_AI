# ADR-002: Languages: Java 21 with Spring Boot for the core, Python for model workers, TypeScript for the web

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

The founder prefers Java and Spring but asked for the best option (DEC-011). Music and language models ship as PyTorch code in Python. JUnit is required for Java components.

## Options considered

1. Python for everything (FastAPI).
2. Java for everything, calling models through ONNX or a separate server.
3. Java core plus Python workers.

## Decision

Option 3. Java 21 (virtual threads) and Spring Boot 3 for the API; Python 3.11 only inside workers; TypeScript for the web app.

## Consequences

Java gives strong typing, mature security libraries, high concurrency with virtual threads and the team's preferred tooling (JUnit 5, Testcontainers). Python is unavoidable for model inference. The two meet only through the queue and object storage, so neither depends on the other's libraries.
