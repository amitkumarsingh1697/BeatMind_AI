# ADR-011: Observability: OpenTelemetry with the Grafana stack

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

SLOs and incident response need metrics, logs and traces at near-zero cost.

## Options considered

1. Commercial APM.
2. OpenTelemetry with Prometheus, Loki, Tempo and Grafana (self-hosted or free cloud tier) plus GlitchTip for errors.

## Decision

Option 2.

## Consequences

Vendor-neutral instrumentation; switching backends later needs no code change.
