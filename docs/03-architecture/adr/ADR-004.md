# ADR-004: Data stores: PostgreSQL, Valkey, Cloudflare R2

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

Transactional data, an append-only ledger, a queue, caching and large audio files are needed at near-zero cost.

## Options considered

1. PostgreSQL plus Valkey plus S3-compatible object storage.
2. A document database.
3. Managed Firebase.

## Decision

Option 1. PostgreSQL 16 for all structured data, ledger and queue; Valkey (BSD-licensed Redis fork) for rate limits and cache; Cloudflare R2 for audio.

## Consequences

Open-source and portable to any cloud, so the free-tier start does not lock BeatMind in. R2 is chosen for no egress fees, which matters because audio downloads dominate bandwidth (A-029, to confirm C-03).
