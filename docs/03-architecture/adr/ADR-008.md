# ADR-008: Identity: Spring Security with Google sign-in and email one-time codes

| Status | Date | Deciders |
| --- | --- | --- |
| Proposed | 2026-10-28 | Founder and developers; drafted by Claude (delegated authority DEC-004, DEC-011) |

## Context

Indian users commonly sign in with Google or phone. SMS OTP in India has per-message costs and sender registration requirements [A].

## Options considered

1. Self-hosted Keycloak.
2. Spring Security with Google OIDC and email OTP; phone OTP later.
3. Third-party auth service.

## Decision

Option 2 for the beta; add phone OTP before public launch (TD-05).

## Consequences

No extra server to run and no per-user fees. Keycloak remains an option if enterprise single sign-on is needed in Phase 2.
