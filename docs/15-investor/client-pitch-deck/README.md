# BeatMind AI client pitch deck (November 2026)

A 23-slide, about 35-minute deck for creator networks, agencies, brands and pilot partners. It is built from PRD v2.1 and the Sprint 6 screens.

| File | What it is |
|---|---|
| `BeatMind_AI_Client_Pitch_Deck.pptx` | The deck. Editable 16:9, with Morph transitions, automatic entrance builds and a looping cover video. Speaker notes are on every slide. |
| `BeatMind_AI_Client_Pitch_Deck.pdf` | Static PDF for email and pre-reads. It contains no motion. |
| `BeatMind_AI_Presenter_Script.docx` | Per-slide objective, key message, notes, talking points, transition and timing. |
| `BeatMind_AI_Presentation_Design_Guide.pdf` | Colour, type, layout, imagery, motion and presenting rules. |
| `BeatMind_AI_Storyboard.md` | Slide-by-slide storyboard. |
| `BeatMind_AI_Asset_Inventory.md` | Every visual: its source, what was generated, and what to replace. |
| `BeatMind_AI_Presentation_Technical_Notes.md` | Build approach, motion, playback per platform, limitations, and how to edit. |
| `source/` | Generators, assets and fonts. Run `bash source/build.sh` to rebuild everything. |

These placeholders must be filled in before any external use:
- partner and presenter names (slide 1);
- team details (slide 19);
- the contact line (slide 23).
