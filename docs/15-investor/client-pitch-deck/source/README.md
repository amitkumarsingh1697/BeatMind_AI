# BeatMind AI client pitch deck · source

- `build.sh`: rebuilds every deliverable into `out/`. See `../BeatMind_AI_Presentation_Technical_Notes.md`, section 6.
- `src/`: generators. Edit `script_content.js` for the words, and `build_deck.js` for the slides.
- `assets/crops/`: crops of the real Sprint 6 screenshots, made by `src/make_crops.sh`.
- `assets/generated/`: 3D renders, backgrounds, glow orbs and the cover video.
- `fonts/`: Manrope and Noto Sans Devanagari (SIL OFL). Install Inter separately.
